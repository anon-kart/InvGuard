Checked all previously unchecked low-level send/call return values in deliver() and reverted with throw on failure. Specifically, the cancellation-fee send to SGX_ADDRESS, normal fee send to SGX_ADDRESS, requester refund call, and callback contract call are now guarded by `if (!...){ throw; }`. This prevents silent failure where contract state/events could indicate successful delivery/refund/callback despite the Ether transfer or external callback failing.

INVARIANTS USED:
Validation confirmed every low-level call in deliver() now has its boolean return value checked before execution continues. Failure reverts the transaction in Solidity 0.4.9, preserving state consistency for request fee flags and unrespondedCnt. Authorization and request-validity guards are unchanged; request accounting remains performed before successful external interactions and is reverted on any failed checked call; existing reentrancy guard variable usage is preserved around call.value/callback external calls.
